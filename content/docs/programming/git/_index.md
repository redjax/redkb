Git is a [version control system](https://en.wikipedia.org/wiki/Version_control) for tracking plaintext (i.e. code & config) files, and the changes made to them over time. This section is *not* a comprehensive guide to Git. The pages in this section are my own personal notes and tips for using the program.

Check the [Git scripts page](./git_scripts.md) for Bash and Powershell scripts that handle some specific Git operations. The ["rewrite git history" page](./rewrite_git_history.md) details the steps I take whenever I need to rewrite an entire Git tree's commit author(s), i.e. if I commit from the wrong account (this is a huge pain in the ass, try to commit from the right account instead of relying on this fix). I also have notes for [sparse checkouts](./sparse_checkout.md), and a [section that shows how to use Git commands and 3rd party tooling to survey a Git repository to make sense of what's inside](./survey-repo/).
